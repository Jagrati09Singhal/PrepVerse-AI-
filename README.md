## 📌 The Problem: The "Resume Reality Gap"

Most engineering students list technologies like **React, Docker, SQL, or Python** on their resumes after completing an introductory course or hobby project. But when asked about core syntax, lifecycle hooks, memory models, or transaction isolation in live placement drives, they freeze due to rusty fundamentals and interview panic.

**PrepVerse AI** replaces intimidating, paragraph-heavy mock vivas with **active retrieval diagnostics**—calibrating questions directly to the candidate's exact college year and active semester courses, and automatically injecting extra practice questions on weak topics until true mastery is achieved.

### 1. 🎓 Academic Year & Semester Calibration
- **1st Year (Freshman):** Programming logic, control flow, functions, and variable truthiness (C/C++, Python, JS).
- **2nd Year (Sophomore):** Core Data Structures (Arrays, Stacks, Queues, Trees, Graphs) & OOP principles (Java/C++).
- **3rd Year (Pre-Final):** Campus recruitment rounds & core CS fundamentals:
  - **Operating Systems:** Deadlocks, CPU scheduling, virtual memory, paging vs. segmentation.
  - **DBMS:** ACID properties, 3NF normalization, B-Tree indexes, transaction isolation levels.
  - **Computer Networks:** TCP 3-way handshake, OSI layers, DNS resolution, UDP vs. TCP.
- **4th Year (Final Year):** High-level System Design, framework internals (React reconciliation, FastAPI ASGI), concurrency, and microservice trade-offs.

### 2. 🛡️ Real-Time AI Camera Proctoring & Anti-Cheat
- Non-intrusive in-browser camera stream analyzing candidate presence.
- Real-time alerts for face disappearance or multi-person presence.
- Window blur and tab-switch telemetry tracking.
- Authentic voice analysis flagging memorized or artificial speech cadences.

### 3. 🎨 Interactive System Design Canvas
- In-browser interactive diagramming canvas integrated directly into System Design viva questions.
- Candidates can place and connect components (Clients, API Gateways, Load Balancers, Microservices, Redis Caches, SQL/NoSQL databases, Message Queues).
- Automatically submitted alongside the candidate's architectural justification.

### 4. 🎙️ Siri AI Voice Companion & Bilingual Guidance
- Floating interactive voice coach with an animated real-time audio wave visualizer.
- Native Web Speech API speech-to-text with WPM (words per minute) pacing feedback.
- Instant bilingual technical translation (Conversational Hindi + English) for candidates to understand complex questions without language barriers.

### 5. 🧘 Pre-Interview Zen Grounding Box
- Grounding module presented prior to the interview countdown.
- Interactive 4-7-8 breathing pacer to reduce cortisol and heart rate.
- Mindset affirmations and automated camera/microphone hardware diagnostic checks.

### 6. 🔍 Plagiarism & LLM Copy-Paste Detection
- In-depth heuristic and semantic fingerprinting that inspects submitted code and text answers.
- Flags verbatim copy-pastes from public documentation and LLM/ChatGPT boilerplate formats.
- Assigns an honesty and authenticity confidence rating to every evaluation.

### 7. 🛡️ Faculty Admin Hub & Batch Telemetry
- Passcode-authenticated administrative console designed for university placement coordinators and professors.
- Batch-wide analytics revealing class deficits (e.g., *"42% struggling with SQL JOINs"*).
- Filter candidate rosters by graduation year, engineering branch, and overall readiness score.

## 🚀 Quick Start (One-Command Launcher)

PrepVerse AI features an intelligent, unified launcher (`app.py`) that checks prerequisites, resolves port conflicts, starts both backend and frontend processes, and launches your default browser:

### Prerequisites
- **Python 3.10+** (tested on Python 3.10, 3.11, 3.12, 3.14)
- **Node.js 18+ & npm**

### Run Application
```bash
# Clone the repository
git clone https://github.com/Jagrati09Singhal/PrepVerse-AI-.git
cd PrepVerse-AI-

# Launch the entire platform with a single command
python app.py
```

### Launcher Interactive Hotkeys (Console)
While `app.py` is running, press any key in your terminal:
- `b` — Open/re-open the application in your default browser.
- `r` — Cleanly restart the FastAPI backend server.
- `c` — Print the 10-step teacher demonstration flow checklist.
- `q` — Gracefully terminate all backend and frontend background processes.

### CLI Flags
```bash
python app.py --reload           # Enable backend hot-reload for active development
python app.py --backend-only     # Launch only FastAPI backend service
python app.py --frontend-only    # Launch only React/Vite frontend service
python app.py --no-browser       # Prevent automatic browser window opening
```

### Access Endpoints
- 🌐 **Web Application:** `http://127.0.0.1:5173` (or `5174` fallback)
- 🛡️ **Faculty Admin Hub:** `http://127.0.0.1:5173/app/admin`
- 📖 **FastAPI Swagger API Docs:** `http://127.0.0.1:8000/docs`
- 🩺 **Health Check Endpoint:** `http://127.0.0.1:8000/health`
